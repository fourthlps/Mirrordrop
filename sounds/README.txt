MIRROR DROP — optional sound files
Drop MP3 files with these exact names into this folder, then run `npm start` again
(or, after building, copy them into dist/sounds/). Missing files are skipped silently.

  countdown-tick.mp3        each number of the final 10-second countdown
  final-hit.mp3             the moment the final countdown starts ("10")
  selection-tick.mp3        every jump of the red highlight
  selection-slowdown.mp3    once, when the highlight starts to slow down
  winner-impact.mp3         the hit when the winner locks in on the map
  winner-celebration.mp3    when the "THE MIRROR HAS CHOSEN" screen appears
